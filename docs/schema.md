# 数据字典

## columns.csv

| 字段 | 类型 | 取值 | 说明 |
|---|---|---|---|
| page | int | 18—118 | 正文页码（附录 119—121 另列） |
| col | int | 1—n | 列号，自右向左 |
| level | int | 0/1/2… | 起笔差（该列首行 − 本页最高行） |
| text | str | — | 原文，含标点；`◉〔…〕`=圈注；`□`=阙文；`〔F3→锚：文〕`=夾注 |
| first | str | 1 字 | 首字 |
| last | str | 1 字 | 末字 |
| chars | int | — | 汉字数（不含标点） |
| flow | enum | 经条/方区/论/篇题 | 语流归属 |
| note | str | — | 校记 |

## meta.json

| 键 | 说明 |
|---|---|
| page | 页码 |
| columns | 该页列数 |
| source | 底本 |
| edition | 数据集版本 |
| note | 附注 |

## 标记约定

| 标记 | 含义 |
|---|---|
| `、` `。` | 原书标点，占一格 |
| `◉` | 圈注起头 |
| `〔…〕` | 注文（圈注或夾注） |
| `□` | 阙文，一字一框 |
| `〔F3→X：Y〕` | 夾注，锚在 X 字后，注文为 Y |
| `〔F5.1〕` | 经框（經） |
| `〔F5.2〕` | 论框（論） |
