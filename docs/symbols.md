# 符号表（版面用语）

| 名 | 形 | 义 |
|---|---|---|
| 顶格 | level 0 | 该页最高行 |
| 降一格 | level 1 | 低一行 |
| 降二格 | level 2 | 低两行 |
| 方区 | flow=方区 | 方独立成栏，药名加黑、剂量小一号、炮制在右 |
| 圈注 | ◉ | 注之起头，一格圈，其后小字 |
| 夾注 | 〔F3→…〕 | 双行小字，锚在某字后 |
| 经框 | 〔F5.1〕 | 方框内一「經」字，标起经 |
| 论框 | 〔F5.2〕 | 方框内一「論」字，标起论 |
| 阙文 | □ | 空框，一字一框 |
| 起笔差 | level | 行位差，非层级 |
