# 康平本《伤寒论》版面复原（Kangping Shanghan Lun Layout Restoration）

> **这不是一份"新校本"，而是一把可以自己去量的尺子。**

本项目把《康平本伤寒论》的**版面**逐页数字化：每一页有几列、每列起笔在哪一行、哪些字是正文、
哪些是注、方在哪里开始。**每个字都能回溯到"页—列—字位"，读者可自行核对。**

---

## 为什么是"版面"

传世的《伤寒论》读本经过宋人重编，条文被重新断句、重新排序。
**康平本保留了抄写时的行款**：顶格、降一格、降二格，方区独立成栏，注用圈、经用框。

**行款本身是语法。**顶格与降格的差别，不是排版美观，而是**谁在说话**。

我们的工作只做一件事：**把行款如实复现，让人可以自己判断。**

## 字段说明（columns.csv）

| 字段 | 含义 |
|---|---|
| `page` | 页码（1—121，正文 p18—p118） |
| `col` | 列号，**自右向左**编号，1 为最右一列 |
| `level` | **起笔差** = 该列首字所在行 − 本页最高行（0=顶格，1=降一格，2=降二格） |
| `text` | 该列原文（含顿号、句号；`◉〔…〕` 为圈注，`□` 为阙文） |
| `first` / `last` | 首字／末字（不含标点） |
| `chars` | 字数（汉字计） |
| `flow` | 语流：`经条` / `方区` / `论` / `篇题` |
| `note` | 校记（宋本对应、异体、待核） |

---

## 三条读法

1. **列 = 简**。一列就是一根竹简，约三十字上下。
2. **level 不是层级，是行位**。原书各列起笔本就不齐，我们不"修齐"。
3. **方是独立的**。方在版面上自成一块，条文里只写"某汤主之"，方随引而出。

## 如何验证一页

1. 打开 `pages/p018/layout.pdf`，与影印原书对看；
2. 打开 `pages/p018/columns.csv`，任取 `col=5`，按 `text` 在影印上找该列；
3. 数它的起笔行，减去本页最高行，应等于 `level`。

**三步都对，这一页就算通过。**
